# 对话风格DNA提取器

同样是聊天，为什么有人让人舒服，有人让人反感？
**提取对话风格特征，学会高情商表达。**

[![HTML](https://img.shields.io/badge/打开即用-无需安装-orange)]()

## 一眼看懂说话风格

- **风格提取**：jieba分词分析对话特征词
- **作者识别**：根据风格特征判断对话来源
- **风格迁移**：5种预设风格一键转换（专业/亲和/犀利/幽默/正式）
- **词云可视化**：关键词词云，直观呈现风格标签

## 怎么用

打开 `web_demo.html` → 输入对话文本 → 查看风格分析
